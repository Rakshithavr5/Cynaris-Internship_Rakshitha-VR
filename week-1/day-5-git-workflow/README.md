
# Week 1 - Day 5: Git Workflow

## Objective
Master Git branching, commits, pull requests,
rebasing, and merge conflict resolution.

## Practical Tasks
- Create feature branches
- Practise Git merge and rebase
- Create a Node.js .gitignore
- Resolve a merge conflict
- Push changes to GitHub
- Create a Pull Request

## Learning Outcomes
- Understand Git branching and commits
- Understand merge vs rebase
- Learn conflict resolution
- Practise professional GitHub workflows
